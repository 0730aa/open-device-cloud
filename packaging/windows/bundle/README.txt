开放云真机平台 · Windows 本机试用包
====================================

这个文件夹里有服务端（网页和接口）、Agent（连接手机的程序），以及它们需要的 Java。
全部在这台电脑上运行，也只有这台电脑能访问。

一、准备（只需要做一次）
------------------------
1. 把整个文件夹放到路径里只有英文字母和数字、没有空格的位置，例如 D:\odc
2. 安装 MySQL 8.4，记住安装时设置的 root 密码：
   https://dev.mysql.com/downloads/mysql/ → 选 8.4 LTS、Windows (x86, 64-bit), MSI Installer
   （下载页底部点 "No thanks, just start my download." 可以不登录直接下载）
3. 手机：设置 → 关于手机 → 连续点「版本号」7 次，打开开发者选项；
   再到开发者选项里打开「USB 调试」

二、启动
--------
1. 双击 start-server.bat 启动服务端（第一次会问 MySQL 的 root 密码，第一次启动要等两三分钟）。
   成功后浏览器会自动打开 http://127.0.0.1:3000
2. 第一次：在登录页点「注 册」，用户名填 sonic、密码自己定，注册后登录。sonic 是超级管理员。
3. 第一次：网页顶部点「设备中心」→「Agent中心」→「新增Agent」，名字随意，保存后复制那一行的 Key。
4. 用数据线连接手机，双击 start-agent.bat（第一次会让你粘贴 Key）。
   手机上弹出「允许 USB 调试吗？」时，勾选「始终允许」再点「允许」；
   之后手机可能会询问是否安装 Sonic 的辅助应用，都选允许/安装。
5. 网页「设备中心」里出现你的手机后，点「马上使用」就能在网页上远程控制它。

三、停止
--------
- 关闭 Agent 的窗口即停止 Agent
- 双击 stop-server.bat 停止服务端

四、文件说明
------------
- check-phone.bat：只检查手机有没有连好
- server\settings.json：MySQL 密码和服务端密钥（删除后，下次启动会重新询问和生成）
- agent\config\application-sonic-agent.yml：Agent 的配置，Key 保存在这里
- 日志：server\logs、agent\logs

五、常见问题
------------
- 提示「连不上 MySQL」：按 Win+R，输入 services.msc 回车，找到 MySQL 开头的服务，右键「启动」。
- 提示「端口被占用」：关闭提示里说的那个程序，或者重启电脑后再试。
- 检测不到手机：换一根能传数据的线；插上后通知栏的 USB 用途选「传输文件」；
  关闭电脑上的手机助手类软件；设备管理器里手机有黄色感叹号时，安装该品牌的 USB 驱动。
- 能看到画面但点不动：小米手机要在开发者选项里打开「USB 调试（安全设置）」；
  OPPO/一加/realme 打开「禁止权限监控」；其他品牌找类似「USB 调试（安全设置）」「模拟点击」的开关。
- 装不上辅助应用：小米打开「USB 安装」；华为/荣耀关闭「监控 ADB 安装应用」。
- Windows 防火墙询问是否允许 Java 访问网络：点「允许」或「取消」都可以，本机试用不受影响。
- 杀毒软件拦截或删除了 agent\plugins 里的文件：把这个文件夹加入信任区后重新解压（里面是 adb 等调试工具）。
